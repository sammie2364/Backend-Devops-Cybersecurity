# Employee Profile Generator

This Python script generates a formatted employee profile card.

## Concepts Practiced

- String concatenation
- String augmentation (`+=`)
- String slicing
- f-strings formatting
- Structured text output

## Employee Code Format

The employee code follows this structure:

DEPT-YEAR-INITIALS-ID

Example:

DEV-2026-JD-001

Extracted values:

- Department → DEV
- Year → 2026
- Initials → JD

## How to Run

```bash
python3 employee-profile-generator.py
